 # Jaison V Thomas — Portfolio

 Static site. No build step, no framework — just HTML/CSS/JS.

 ## Run locally
 Open `index.html` in a browser, or in VS Code install the **Live Server**
 extension → right-click `index.html` → "Open with Live Server".

 ## Edit
 - `index.html` — content/structure
 - `css/style.css` — all styling
 - `js/script.js` — starfield background + typewriter effect

 ## Deploy (Vercel)
 1. Push this folder to a GitHub repo
 2. Go to vercel.com → New Project → import the repo
 3. Framework preset: "Other" (it's static, no build command needed)
 4. Deploy — live in ~60 seconds, get a shareable `.vercel.app` URL

 ## Deploy (alternative: Netlify Drop)
 Go to app.netlify.com/drop and drag this whole folder in. Live instantly,
 no GitHub needed. Good for quick shares, worse for ongoing edits.
